# Planet map texture credits

The Tracking Station and Earth flight globe load equirectangular planet maps from Solar System Scope's free planetary texture pack:

- Earth day map: `2k_earth_daymap.jpg`
- Luna: `2k_moon.jpg`
- Mars: `2k_mars.jpg`
- Jupiter: `2k_jupiter.jpg`
- Saturn: `2k_saturn.jpg`

Source: https://www.solarsystemscope.com/textures/

Licence: Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

The map pack is based on NASA imagery and elevation data. Phobos, Europa, and Titan use solid-color illustrative globes because this build does not include a suitable global texture for those bodies. If the remote texture host is unavailable, each globe falls back to its solid base colour.
